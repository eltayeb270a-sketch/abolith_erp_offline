# نظام أبوليث ERP — النسخة النهائية

## الملفات
- `index.html` — التطبيق الكامل.
- `manifest.json` — إعداد التثبيت كتطبيق.
- `sw.js` — تشغيل واجهة التطبيق بدون اتصال بعد أول تحميل.

## النشر على GitHub Pages
ارفع الملفات الثلاثة إلى جذر المستودع، ثم:
Settings → Pages → Deploy from a branch → main → /(root) → Save.

## ملاحظة
البيانات تحفظ محليًا في المتصفح. النسخ الاحتياطي والاستعادة من داخل النظام.
